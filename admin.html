💡 네이버 API 연동 없이 뉴스 스크래핑이 가능한가요?

네, 네이버 검색 API를 연동하지 않고도 충분히 자동 스크래핑 구축이 가능합니다. 실무에서는 아래 3가지 방식 중 사내 서버 환경에 맞춰 선택합니다.

수집 방식 네이버 API 필요 여부 특징 및 실무 장단점
1. Google News RSS 피드 파싱
(가장 추천 · 무료/무제한)		 ❌ 불필요 키워드별 RSS URL(news.google.com/rss/search?q=키워드)을 서버(Python/Node)에서 주기 호출. API 키 발급·일일 한도 제한이 없고, 주요 제약전문지(데일리팜·의약뉴스·메디파나 등) 기사가 모두 수집됨.
2. 주요 제약·경제 언론사 직접 RSS / 크롤링 ❌ 불필요 의약뉴스, 약사공론, 메디파나뉴스, 매일경제 등 타겟 매체 RSS 및 웹 페이지를 스케줄러(Cron)로 수집.
3. 네이버 검색 API
(기존 방식)		 ⭕ 필요 (일 25,000건 무료) 국내 매체 커버리지가 가장 넓고 빠름. 다만 네이버 정책상 openapi.naver.com은 브라우저 직접 호출(CORS)이 차단되므로 반드시 백엔드 프록시 서버가 필요함.

📌 핵심 운영 로직 반영 사항:
• 월요일 수집 확장: 요일이 월요일(getDay() === 1)인 경우 자동으로 금요일 오전 ~ 월요일 발행 전(72시간) 기사를 스크래핑합니다.
• 과거 중복 제거: 기사의 정규화된 제목(특수문자 제거 후 유사도 비교) 및 원문 URL 해시를 DB에 저장하여 직전 모니터링에 노출된 기사는 자동 필터링합니다.
